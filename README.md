# Proxy Installer (Ubuntu)

Простой скрипт для установки **HTTP-прокси с авторизацией (user:password)** на Ubuntu-сервере.  
На выходе вы получаете готовую строку вида:

```
http://user:password@your_server_ip:8080
```

Эту строку можно сразу использовать в `.env`, Docker, Python (`requests`, `aiohttp`), Telegram-ботах и т.д.

---

## 📦 Что делает скрипт

- Устанавливает **Squid**
- Настраивает **HTTP-proxy**
- Включает **Basic Auth**
- Генерирует логин и пароль
- Выводит готовый proxy-URL после установки

---

## 🚀 Быстрая установка (one-liner)

Выполните **одну команду** на чистом Ubuntu-сервере:

```bash
. <(wget -qO- https://raw.githubusercontent.com/g7AzaZLO/proxy_installer/main/install_proxy.sh)
```

❗ Запускать **от root** или через `sudo`.

---

## ✅ Результат

После выполнения скрипта вы увидите примерно такой вывод:

```
HTTP Proxy:
http://proxyuser:AbC9xYkL2Q@123.45.67.89:8080
```

Это и есть готовый прокси.

---

## 🧪 Проверка работы

```bash
curl -x http://USER:PASS@IP:8080 https://api.ipify.org
```

Если вернулся IP сервера — прокси работает корректно.

---

## 🧩 Пример использования в .env

```env
FAST_PRICE_PROXY=http://proxyuser:AbC9xYkL2Q@123.45.67.89:8080
```

---

## 🛠 Требования

- Ubuntu 20.04 / 22.04 / 24.04
- Открытый порт **8080**
- Доступ в интернет

---

## 📂 Файлы

- `install_proxy.sh` — основной установочный скрипт

---

## ⚠️ Примечания

- Логи отключены (минимальный footprint)
- Кэш Squid отключён
- Прокси предназначен для **серверных приложений**, а не публичного доступа
