# Proxy Installer (Ubuntu)

Интерактивный скрипт для настройки прокси на Ubuntu с выбором типа:

- `HTTP (Squid)`
- `SOCKS5 (Dante)`

Скрипт запускается в меню и поддерживает управление пользователями, портами и проверку статуса сервисов.

---

## Что умеет скрипт

### Главное меню

- `HTTP (Squid)`
- `SOCKS5 (Dante)`
- `Выход`

Навигация в интерактивном режиме: стрелки `↑/↓` + `Enter`.  
Если запуск неинтерактивный (без TTY), используется fallback с выбором цифрами.

### HTTP (Squid)

- Установка и базовая настройка `squid`
- Создание/обновление пользователей (`htpasswd`)
- Удаление пользователей
- Смена порта
- Просмотр статуса `squid`

### SOCKS5 (Dante)

- Установка `dante-server`, `ufw`, `fail2ban`
- Создание/обновление пользователей Linux для auth
- Удаление пользователей
- Смена порта
- Просмотр статуса `sockd` и `fail2ban`

## Быстрый запуск

### Вариант 1: one-liner

```bash
. <(wget -qO- https://raw.githubusercontent.com/g7AzaZLO/proxy_installer/main/install_proxy.sh)
```

### Вариант 2: локально из репозитория

```bash
chmod +x install_proxy.sh
sudo ./install_proxy.sh
```

Запускать нужно от `root` или через `sudo`.

---

## Пример сценария работы

1. Запускаешь `install_proxy.sh`
2. В главном меню выбираешь тип прокси:
   - `HTTP (Squid)` или
   - `SOCKS5 (Dante)`
3. В подменю выполняешь нужное действие:
   - установка/настройка
   - управление пользователями
   - смена порта
   - статус

---

## Проверка прокси

### Проверка HTTP (Squid)

```bash
curl -x http://USER:PASS@IP:PORT https://api.ipify.org
```

### Проверка SOCKS5 (Dante)

```bash
curl --socks5 USER:PASS@IP:PORT https://ifconfig.me
```

Если возвращается IP сервера, прокси работает.

## Важные замечания по безопасности

- Для `HTTP (Squid)` используется Basic Auth.
- Для `SOCKS5 (Dante)` включается `fail2ban` и настраивается `ufw`.
- Не используй прокси как публичный open-access сервис.
- Рекомендуется:
  - выбирать нестандартные порты,
  - использовать сложные пароли,
  - ограничивать доступ по IP (при необходимости).
